# NetSpy // Network Inspector 🌐

A sleek, cyberpunk-styled cybersecurity utility and IP geolocation dashboard that captures public network metadata in real time using asynchronous API fetching.

## 🛡️ Key Features
* **Automated Device Profiling:** Instantly reads and traces your client machine's network location profile upon page load.
* **On-Demand Domain Scanning:** Allows users to query any public IPv4/IPv6 address or domain string to inspect server clusters.
* **Granular Network Metadata:** Decodes telemetry strings including Internet Service Provider (ISP), region/state boundaries, timezone shifts, and local currencies.
* **Asynchronous Engine:** Utilizes modern asynchronous architecture to prevent webpage reloads during packet transmission.

## 🛠️ Built With
* HTML5 (Semantic document components)
* CSS3 (Flexbox, Grid systems, and CSS variables)
* JavaScript (ES6 asynchronous `fetch` requests and `async/await` handling)
* [ipapi.co](https://ipapi.co/) - Public REST Geolocation API
